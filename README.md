# Columbia Course Atlas

An interactive prerequisite map of seven Columbia School of General Studies majors and two minors using the 2026–27 General Studies Bulletin and current department guidance.

Select a program from the dropdown. Solid arrows show prerequisites and dashed arrows show corequisites. Open a course for its full name, points, published description, prerequisite paths, and available public syllabus. On a selected course, open **Change selected course** to filter available alternatives and replace the selection inside the course panel. Choices are saved in your browser.

The collapsible **Plan** sidebar shows total courses and points, including prerequisites and corequisites. Each unique course counts once. Repeated required enrollments count their full points. Default options use the fewest distinct prerequisite courses, lowest points, then lowest course number. Choices requiring individual approval are available in the picker.

Open-ended electives include indexed options and an **Add another eligible course** form. Department permission, placement, section-specific prerequisites, and equivalent background appear where applicable. Each course links to its individual Bulletin listing. Older records with missing full descriptions show a verified summary where available.

## Run locally

Run a static server from the repository directory.

    python -m http.server 8080

Open http://localhost:8080. GitHub Pages serves the same static files from the repository root.
