# Columbia Course Atlas

An interactive prerequisite map of seven Columbia College majors and two minors using the 2026–27 Bulletin and current department guidance.

Open **Course map** to see required courses, chosen alternatives, and their prerequisite chains. Solid arrows show prerequisites and dashed arrows show corequisites. Open a course for its points, description summary, alternative pathways, and available public syllabus. **Requirements** lets you expand and filter course options and edit a selection. Choices are saved in your browser.

The published requirement appears above the calculated point totals. Program points count the selected requirement courses. The second total includes additional prerequisites and corequisites, counted once each. Repeated required enrollments count their full points. Default options use the fewest distinct prerequisite courses, lowest points, then lowest course number. Choices requiring individual approval are available in the picker.

Open-ended electives include indexed options and an **Add a course** form. Department permission, placement, section-specific prerequisites and equivalent background are noted where applicable. Each course links to the individual Bulletin listing for its full description, and additional sources appear where available.

## Run locally

Run a static server from the repository directory.

    python -m http.server 8080

Open http://localhost:8080. GitHub Pages serves the same static files from the repository root.
